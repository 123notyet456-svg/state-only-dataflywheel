# 实验结果汇总

## 数据集与质量检查

Dataset v1（第 1 版数据集）按 Episode（轨迹片段 / 回合）划分训练 / 验证 / 测试集为 16,000 / 2,000 / 2,000 帧，对应 40 / 5 / 5 个 Episode。状态和动作各为 14 维。拆分检查、形状检查、缺失值检查、轨迹与时间戳连续性检查均通过；训练集状态、动作和时间戳缺失值计数均为 0。

## 基线与失败定位

| 指标 | 结果 |
|---|---:|
| 初始基线测试帧数 | 2,000 |
| 初始基线总体 MAE（平均绝对误差） | 0.00907244 |
| 初始基线总体 MSE（均方误差） | 0.000204616 |
| 最差帧 | Episode 49 / Frame 294 |
| 最差帧 MAE | 0.0277377 |
| 最差帧状态距离指标 | 0.7548 |

失败集中在 Episode 49 的 Frame 292–300。`right_wrist_rotate`（右腕旋转，Dim12）动作变化与误差的相关系数为 +0.7115，高动态与普通动态误差比为 6.032 倍；Dim10 为 4.36 倍，Dim11 为 4.13 倍。

## v2 / v3 动态帧过采样

高动态样本采样占比由约 9.98% 提升至 24.95%。v2 与 v3 是不同干预及评测结果，需分开解读：

| 指标 | v2 全局过采样 | v3 Dim12 定向过采样 |
|---|---:|---:|
| 整体高动态 MAE 相对 v1 | -3.76% | +3.59% |
| Dim12 高动态误差相对 v1 | -20.12% | -27.05% |
| Dim12 普通动态误差相对 v1 | +24.70% | +87.22% |

v3 在目标关节高动态上的改善伴随普通动态误差明显上升，说明针对局部切片的数据加权有泛化取舍；因此不能把高动态占比提高本身视为全面质量改善。

## 时间上下文诊断

Delta State（状态变化量，`ΔState = State(t) - State(t-1)`）加入后，KNN（K 近邻）诊断得到：总体 MAE 下降 7.67%，Dim12 总体 MAE 下降 17.76%，Dim12 高动态 MAE 下降 17.82%。这是特征诊断结果，不是最终神经网络受控实验指标。

时间状态神经网络输入为 `State(t) + ΔState(t)`，由 14 维增至 28 维；最佳 Epoch（训练轮次）为 46，最佳验证损失为 `7.014e-05`。

## 最终匹配控制实验

Matched-Control Experiment（匹配控制实验）在完全相同的 1,995 个测试帧上比较匹配 State-only 与 Temporal State 模型；其中 Dim12 高动态帧为 201 帧。

| 指标 | 匹配 State-only | Temporal State | 相对变化 |
|---|---:|---:|---:|
| 总体 MAE | 0.008924 | 0.006507 | -27.08% |
| 总体 MSE | 0.0002071 | 0.0000941 | -54.54% |
| Dim12 总体 MAE | 0.014967 | 0.010072 | -32.71% |
| Dim12 高动态 MAE | 0.056522 | 0.021939 | -61.18% |
| Dim12 普通动态 MAE | 0.010311 | 0.008742 | -15.22% |
| Episode 49 MAE | 0.010638 | 0.008173 | -23.17% |
| Episode 49 Frame 292–300 MAE | 0.027062 | 0.011410 | -57.84% |
| 同区域 Dim12 MAE | 0.091338 | 0.028095 | -69.24% |
| Episode 49 Frame 294 MAE | 0.028482 | 0.012716 | -55.35% |
| Frame 294 Dim12 误差 | 0.093116 | 0.034879 | -62.54% |

变化百分比按报告中的匹配 State-only 结果计算。初始基线使用 2,000 帧，最终匹配实验使用 1,995 帧；判断时间状态的增益应以最终同帧对照为准。

## 结论与限制

实验支持时间上下文 / 状态表征缺口是主要问题，动态数据分布是次要因素：过采样能重新分配模型关注点，但定向过采样产生普通动态退化；加入状态变化量后，同一测试帧上的总体和原失败区域均有改善。此结论限于当前离线数据与模型设置，不等同于真实机器人闭环控制效果。
